# Encantos Literários

Landing page responsiva e animada de um clube de assinatura literário, criada com HTML e CSS puro a partir do Figma da Rocketseat.

## Recursos

- Hero com chamada para assinatura.
- Kit mensal com entrada sequencial dos itens.
- Três planos de assinatura.
- Rodapé com redes sociais e navegação.
- Animações respeitam `prefers-reduced-motion`.

Abra `index.html` no navegador. Não há instalação ou dependências.
